Документация API

Аутентификация

1. Через API ключ

Добавьте заголовок Authorization к каждому запросу:

Authorization: Bearer YOUR_API_KEY

2. Через ESUID API

Для использования ESUID API:

  1. Получите ESUID токен в настройках
  2. Добавьте заголовок к запросам:
Authorization: ESUID YOUR_ESUID_TOKEN
ESUID API позволяет интегрировать хранилище с другими сервисами Eventshock

Endpoints

Файлы

GET /api/files/

Получение списка файлов

curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/files/" \
    -H "Authorization: ESUID YOUR_ESUID_TOKEN"

Ответ:

{
    "files": [
        {
            "id": 1,
            "filename": "document.pdf",
            "uploaded_at": "2024-01-01T12:00:00Z",
            "size": 1024,
            "type": "document",
            "download_url": "http://localhost:8000/storage/download/TOKEN/",
            "public": false
        }
    ],
    "storage": {
        "used": "1.5 GB",
        "total": "10 GB",
        "percent": 15
    }
}
POST /api/files/upload/

Загрузка файла

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/files/upload/" \
    -H "Authorization: ESUID YOUR_ESUID_TOKEN" \
    -F "file=@local_file.pdf"

Ответ:

{
    "success": true,
    "file": {
        "id": 2,
        "filename": "local_file.pdf",
        "size": 2048,
        "download_url": "http://localhost:8000/storage/download/TOKEN/"
    }
}
GET /api/files/{id}/

Информация о файле

curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/files/1/" \
    -H "Authorization: ESUID YOUR_ESUID_TOKEN"
DELETE /api/files/{id}/

Удаление файла

curl -X DELETE "{{ request.scheme }}://{{ request.get_host }}/api/files/1/" \
    -H "Authorization: ESUID YOUR_ESUID_TOKEN"

Примеры интеграции

JavaScript

// Инициализация ESUID клиента
const storage = new EventshockStorage({
    token: 'YOUR_ESUID_TOKEN',
    baseUrl: '{{ request.scheme }}://{{ request.get_host }}'
});

// Получение списка файлов
storage.getFiles()
    .then(files => console.log(files))
    .catch(error => console.error(error));

// Загрузка файла
const file = document.querySelector('input[type="file"]').files[0];
storage.uploadFile(file)
    .then(result => console.log(result))
    .catch(error => console.error(error));

Python

from eventshock_storage import EventshockStorage

# Инициализация клиента
storage = EventshockStorage(
    token='YOUR_ESUID_TOKEN',
    base_url='{{ request.scheme }}://{{ request.get_host }}'
)

# Получение списка файлов
files = storage.get_files()

# Загрузка файла
with open('local_file.pdf', 'rb') as f:
    result = storage.upload_file(f)
    print(result['download_url'])
