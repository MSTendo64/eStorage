URL прокси-сервера для загрузки файлов по ссылке. Оставьте пустым для использования встроенных прокси-сервисов.
Для настройки собственного прокси-сервера на Ubuntu см. файл PROXY_SETUP.md
Формат URL:
- http://your-server.com/proxy?url= (URL добавляется автоматически)
- http://your-server.com/proxy?url= (с параметром url)
Примеры публичных прокси:
- https://api.allorigins.win/raw?url=
- https://corsproxy.io/?
Список доменов (по одному на строку), для которых сразу использовать прокси при загрузке файлов.
Если домен указан в этом списке, прокси будет использован сразу, без попытки прямой загрузки.
Примеры:
- example.com - будет использован прокси для всех URL с этим доменом
- subdomain.example.com - только для конкретного поддомена
- example.org - другой домен
Оставьте пустым, если не нужно автоматически использовать прокси для определенных доменов.
